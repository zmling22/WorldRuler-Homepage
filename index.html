01 / THE IDEA

A world that follows
your rules.

Change what an action means.
Keep what the world remembers.

A switch can open a door before it comes into view. A defeated monster can leave a key that is still there after you return. Generative worlds need to preserve the logic behind these interactions—and make its consequences visible.

WorldRuler connects rule execution, video generation, and perceptual feedback through an executable 3D rule graph.

01 / PERSIST

Resume the world.

Restore rule definitions, dependencies, and object states together—not just the last image.

02 / GROUND

Find the right object.

Bind rule entities to visual instances, including objects that appear only later.

03 / REALIZE

Make the state visible.

Guide designated attributes while preserving compatible appearance, motion, and unrelated content.

02 / THE METHOD

Execute the rule.
Realize the consequence.

A persistent rule graph and a visual generation loop connect symbolic state to what you see.

RULE GRAPH

Persistent, executable state.

Rules, dependencies, object identities, attributes, and spatial information live in a shared representation.

DYNAMIC BINDING

State before first sight.

Stored rule targets constrain newly visible objects from their first appearance, with feedback refining correspondences.

ATTRIBUTE REPLACEMENT

Local, targeted control.

A frozen reader estimates object attributes. A trained writer applies rule-directed corrections during generation.

A closer look at attribute replacement & paired training＋

Counterfactual reconstruction and bidirectional attribute swapping train the replacement operator using paired videos. The video generator and attribute reader remain frozen.

05 / THE DATASET

RuleVerse.

One world.
Two possible outcomes.

Paired rule-driven interactions.
Collected in Habitat and GTA V.

Each pair shares the scene configuration and action intent, while a designated rule mechanism is enabled or disabled. The resulting videos capture different state evolutions, with annotations of states, events, and rule outcomes.

Scene-aware splits separate training and test groups. The collection pipeline covers object attributes, spatial relationships, and effects that begin outside the current view.
